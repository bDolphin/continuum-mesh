🔄 HOW IT WORKS NOW

STORE (All tools use same pattern):
  1. User selects text or clicks store
  2. Content script sends: chrome.runtime.sendMessage({ type: 'STORE_MEMORY' })
  3. Service worker routes to: POST /store (daemon)
  4. Backend creates embedding and stores memory
  ✅ Memory instantly available across all tools

RECALL (Unified semantic search):
  1. User presses Ctrl+Shift+R or searches
  2. Content script sends: chrome.runtime.sendMessage({ type: 'RECALL_MEMORIES' })
  3. Service worker routes to: GET /recall (daemon)
  4. Backend calculates cosine similarity scores
  5. Results ranked by relevance
  ✅ Shows memories from ChatGPT, Perplexity, and web all together
